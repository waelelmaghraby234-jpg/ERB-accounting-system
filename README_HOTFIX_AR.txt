Cairo Group ERP v0.5.1 Hotfix

الإصلاح:
- يمنع فشل تحديث قاعدة البيانات عند وجود قيود مرحلة قديمة.
- يتم تعطيل Triggers منع التعديل مؤقتاً أثناء تعبئة حقول العملة الجديدة ثم إعادتها فوراً.
- لا يتم حذف أو تعديل القيم المحاسبية الأصلية للقيود.

طريقة التركيب:
1) ارفع محتويات هذا المجلد إلى نفس GitHub Repository مع الاستبدال.
2) اجعل AUTO_MIGRATE=true في Render.
3) انتظر حتى تصبح الخدمة Live.
4) افتح /health وتأكد أن الإصدار 0.5.1.
5) بعد النجاح غيّر AUTO_MIGRATE=false.
