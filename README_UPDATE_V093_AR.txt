Cairo Group ERP V0.9.3 — IFRS Primary Statements Layout
=========================================================

هذا التحديث يعيد تصميم:
1) قائمة الأرباح أو الخسائر والدخل الشامل الآخر.
2) قائمة المركز المالي.

التصميم مطابق بصرياً للنموذج المرسل من المستخدم مع تحسينات IFRS:
- اسم الشركة والاسم القانوني وعنوان القائمة في منتصف الصفحة.
- عمود البيان، رقم الإيضاح، السنة الحالية، سنة المقارنة، وعملة العرض.
- الأرقام السالبة بين أقواس والصفر كشرطة.
- مجاميع فرعية وخطوط مزدوجة للمجاميع النهائية.
- إيضاح أن الملاحظات جزء لا يتجزأ من القوائم.
- مكان توقيع المدير المالي ورئيس مجلس الإدارة.
- العرض بالعربية أو الإنجليزية حسب لغة المستخدم.
- طباعة A4 وحفظ PDF وتصدير Excel.
- قائمة المركز المالي: أصول غير متداولة، أصول متداولة، حقوق ملكية، التزامات غير متداولة، التزامات متداولة.
- قائمة الدخل: الإيرادات، التكلفة، مجمل الربح، المصروفات التشغيلية والإدارية، الإهلاك، ربح النشاط، الإيرادات والمصروفات الأخرى، الضريبة، ربح العام، الدخل الشامل الآخر.

طريقة التحديث:
1. ارفع محتويات هذا المجلد إلى GitHub مع استبدال الملفات القديمة.
2. في Render اجعل AUTO_MIGRATE=true مؤقتاً.
3. استخدم Manual Deploy > Clear build cache & deploy.
4. تأكد أن /health يعرض الإصدار 0.9.3.
5. افتح النظام واضغط Ctrl+F5.
6. بعد نجاح التحديث غيّر AUTO_MIGRATE=false.

تنبيه:
التصميم والعرض موجهان وفق IFRS، لكن إصدار قوائم مالية قانونية متوافقة بالكامل يتطلب مراجعة ربط الحسابات والسياسات المحاسبية والإفصاحات والملاحظات بواسطة الإدارة المالية والمراجع الخارجي.
