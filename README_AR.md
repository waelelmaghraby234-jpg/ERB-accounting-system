# Holding ERP Cloud — نسخة الواجهة المحاسبية V2

هذه النسخة تستبدل واجهة الاختبار القديمة بواجهة عربية فعلية تشمل:

- لوحة تحكم.
- إدارة الشركة القابضة والشركات التابعة وكيان الاستبعادات.
- دليل حسابات موحد للمجموعة.
- حسابات تشغيلية لكل شركة.
- إدخال قيد يومية متعدد السطور مع فحص توازن المدين والدائن.
- ميزان مراجعة لكل شركة.
- ميزان مراجعة مجمع للمجموعة.
- بيانات المستخدم وتسجيل الخروج.

## التحديث فوق النسخة الموجودة

1. فك ضغط الملف.
2. افتح Repository الحالي في GitHub.
3. ارفع محتويات المجلد كاملة ووافق على استبدال الملفات القديمة.
4. اضغط Commit changes.
5. سيبدأ Render النشر تلقائياً، أو استخدم Manual Deploy → Deploy latest commit.
6. بعد ظهور Live افتح رابط النظام واعمل Refresh باستخدام Ctrl+F5.

لا تغيّر Environment Variables الحالية. قاعدة البيانات الموجودة وبيانات الدخول ستستمران كما هي.
