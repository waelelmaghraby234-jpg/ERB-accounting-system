# Cairo Group Holding ERP — V3

نسخة تشغيلية أولى لإدارة مجموعة شركات متعددة على PostgreSQL/Supabase وRender.

## البيانات الافتراضية التي يتم إنشاؤها

- Cairo Group Holding — `HOLD`
- شركة الفنادق — `HOTE`
- شركة التطوير — `DEV`
- شركة الإدارة — `MGT`
- استبعادات المجموعة — `ELIM`
- العملة: EGP
- السنة المالية: 1 يناير إلى 31 ديسمبر
- دليل حسابات موحد وحسابات محلية لكل شركة
- فرع رئيسي ومركز تكلفة عام لكل شركة

## الوحدات الموجودة

- الشركات والفترات المالية
- دليل حسابات المجموعة وحسابات الشركات
- القيود اليومية ودفتر الأستاذ وميزان المراجعة
- قائمة الدخل والمركز المالي والتجميع
- العملاء والموردون
- فواتير المبيعات والمشتريات مع إنشاء قيود آلية
- الحسابات البنكية وسندات القبض والصرف
- فئات الأصول وسجل الأصول والإهلاك الشهري
- المستخدمون والأدوار وسجل التدقيق

## التحديث على النظام الحالي

1. ارفع محتويات هذا المجلد إلى نفس GitHub Repository مع استبدال الملفات القديمة.
2. في Render افتح `Environment`.
3. غيّر `AUTO_MIGRATE` إلى `true` مؤقتاً.
4. اضغط `Save, rebuild, and deploy` أو انتظر Auto Deploy من GitHub.
5. بعد ظهور `Live` افتح رابط البرنامج واضغط `Ctrl + F5`.
6. بعد التأكد من ظهور الشركات والشاشات الجديدة، يمكن ترك `AUTO_MIGRATE=true` لأن ملفات SQL الحالية idempotent، أو تغييره إلى `false` بعد نجاح الترقية.

## تحذيرات مهمة

- احتفظ بنسخة احتياطية من Supabase قبل استخدام بيانات مالية حقيقية.
- لا ترفع ملف `.env` أو كلمات المرور إلى GitHub.
- لا تستخدم النسخة بلا مراجعة محاسب قانوني لإعداد الضرائب والإقفالات والسياسات المحاسبية.
- ربط التحصيلات والمدفوعات بفواتير محددة (Allocations) والعملات الأجنبية والضرائب المصرية التفصيلية تحتاج مرحلة تطوير تالية.
