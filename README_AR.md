# Cairo Group Holding ERP — V0.6.0

تحديث إدارة وتقارير لنظام الحسابات السحابي متعدد الشركات.

## الإضافات

- **تصدير Excel** من أي شاشة أو تقرير ظاهر. ينتج ملف `.xls` متوافقاً مع Microsoft Excel.
- **PDF / معاينة طباعة** من أي شاشة، مع اختيار `Save as PDF` من نافذة الطباعة.
- تقرير **سجل القيود خلال فترة** من تاريخ إلى تاريخ، مع تصفية اختيارية حسب الحساب وحالة القيد.
- تعديل اسم المجموعة المالكة من داخل النظام.
- تعديل اسم وكود واسم قانوني ونسبة ملكية وعملة الشركة القابضة أو التابعة.
- تعديل المستخدم: الاسم، البريد، الدور، الشركة، الصلاحيات، الحالة وكلمة المرور.
- حذف آمن للمستخدم عن طريق إيقافه مع الاحتفاظ بسجل التدقيق.
- تعديل حسابات شجرة المجموعة ونقلها بين الحسابات الرئيسية، مع منع الدوائر في الشجرة.
- نموذج شجرة حسابات تفصيلي متعدد المستويات يشمل:
  - النقدية والبنوك والعملاء والمخزون.
  - الأصول الثابتة ومجمع الإهلاك.
  - مشروعات تحت التنفيذ.
  - الموردين والمستحقات والضرائب.
  - القروض قصيرة وطويلة الأجل.
  - رأس المال والاحتياطيات والأرباح المرحلة.
  - إيرادات النشاط والإيرادات الأخرى.
  - تكلفة الإيرادات والمصروفات التشغيلية والإدارية والتمويلية.

> النموذج المحاسبي المرفق نموذج مهني قابل للتخصيص، وليس بديلاً عن مراجعة المستشار المالي والضريبي عند اعتماد دليل نهائي ملزم قانونياً.

## التثبيت

1. ارفع كل محتويات المجلد إلى مستودع GitHub الحالي مع استبدال الملفات القديمة.
2. في Render اجعل `AUTO_MIGRATE=true` لأول نشر بعد التحديث.
3. انتظر حتى تظهر الحالة `Live`.
4. افتح `/health` وتأكد أن الإصدار `0.6.0`.
5. افتح النظام واضغط `Ctrl + F5`.
6. بعد نجاح التشغيل غيّر `AUTO_MIGRATE=false` وأعد النشر.

لا تغيّر `DATABASE_URL` أو `JWT_SECRET`.

## ملاحظات الصلاحيات

- إدارة الشركات والمجموعة: مدير المجموعة فقط.
- إدارة المستخدمين: مدير المجموعة فقط.
- إدارة شجرة الحسابات: صلاحية `ACCOUNT_MANAGE`.
- عرض وطباعة التقارير: صلاحية `REPORT_VIEW`.
- حذف المستخدم هو حذف تشغيلي آمن `Soft Delete` للحفاظ على سجل القيود والتدقيق.
