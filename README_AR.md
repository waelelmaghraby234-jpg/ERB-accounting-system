# Cairo Group Holding ERP — إصدار 0.5.0

هذا التحديث يضيف الملاحظات التشغيلية المطلوبة:

- إنشاء حسابات رئيسية وتجميعية غير قابلة للحركة، وحسابات فرعية تحتها.
- إدارة العملات وأسعار الصرف (SPOT / AVERAGE / CLOSING).
- تقييم فواتير المبيعات والمشتريات بالعملة الأصلية وبالجنيه المصري.
- حسابات بنكية متعددة العملات وإعادة تقييم أرصدتها.
- إدخال أرصدة افتتاحية مستقلة لكل شركة.
- حفظ قيد اليومية كمسودة حتى لو لم يتوازن بعد.
- تعديل أو حذف القيد المسودة، ثم ترحيله بعد المراجعة.
- منع تعديل أو حذف القيود المرحّلة.
- تطبيق صلاحيات الخادم للأدوار: مدير مالي، محاسب، مراجع، مشاهدة.
- معاينة وطباعة القيود والفواتير والتقارير، مع إمكانية الحفظ PDF من المتصفح.

## التحديث

1. ارفع محتويات هذا المجلد إلى جذر مستودع GitHub الحالي واستبدل الملفات.
2. في Render اجعل `AUTO_MIGRATE=true` لأول نشر لهذا الإصدار.
3. انتظر حتى تصبح الخدمة `Live`.
4. افتح `/health` وتأكد أن النسخة `0.5.0`.
5. افتح البرنامج واضغط `Ctrl+F5`.
6. بعد نجاح التحديث يمكن إعادة `AUTO_MIGRATE=false`.

لا تغيّر `DATABASE_URL` أو `JWT_SECRET`.

## قواعد القيود

- المسودة يمكن أن تكون غير متوازنة، ويمكن تعديلها أو حذفها حسب الصلاحية.
- الترحيل يتطلب سطرين على الأقل وتساوي إجمالي المدين والدائن.
- القيد المرحل غير قابل للتعديل أو الحذف.
- الأرصدة الافتتاحية تُنشأ كقيد من نوع `OPENING` ويمكن حفظها كمسودة أولاً.
