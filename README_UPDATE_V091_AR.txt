Cairo Group ERP V0.9.1 - النسخة المدمجة

هذه النسخة تعيد وظائف V0.7 وتضيف دورة العملاء والموردين من V0.8 دون استبدال النسخة بفرع ناقص.

المزايا:
- إدارة المستخدمين: إنشاء، تعديل، صلاحيات، إيقاف، وحذف تشغيلي آمن.
- واجهة عربية/إنجليزية مع زر تبديل في تسجيل الدخول وداخل النظام.
- قائمة الربح أو الخسارة وقائمة المركز المالي بعرض IFRS، مقارنة وفواصل وإجماليات.
- تصفير شركة مع الاحتفاظ بالشجرة.
- تصفير النظام بالكامل أثناء التجربة فقط وإعادة إنشاء حساب المدير.
- فواتير العملاء والموردين وطرق السداد آجل/نقدي/بنك.

متغيرات Render أثناء التجربة:
AUTO_MIGRATE=true
ALLOW_COMPANY_RESET=true
ALLOW_FULL_TRIAL_RESET=true

بعد نجاح التشغيل:
AUTO_MIGRATE=false
وبعد انتهاء التجربة:
ALLOW_COMPANY_RESET=false
ALLOW_FULL_TRIAL_RESET=false
